# Security Policy

## Supported Versions

The published GitHub Pages site is a static, pre-rendered page with no server-side components. The latest `main` branch is always the supported version.

## Reporting a Vulnerability

Please report security issues privately using [GitHub Security Advisories](https://github.com/aecomet/aecomet.github.io/security/advisories/new).

You can expect an acknowledgement within 72 hours. Once a fix is available, the vulnerability will be disclosed responsibly after it has been resolved.
